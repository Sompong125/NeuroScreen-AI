# NeuroScreen-AI
ต้นแบบระบบช่วยคัดกรองความเสี่ยง ADHD จากสัญญาณคลื่นไฟฟ้าสมอง (EEG) โดยใช้การประมวลผลสัญญาณ การสร้าง Spectrogram และปัญญาประดิษฐ์ CNN เพื่อสนับสนุนการประเมินเบื้องต้น ไม่ใช่เครื่องมือสำหรับวินิจฉัยโรค | EEG-based ADHD screening support prototype using spectrograms and CNN. For research purposes only; not a diagnostic tool.
